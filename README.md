В проекте проводится разведочный анализ транзакций кофейного
  автомата на основе открытого датасета Coffee Sales с Kaggle.

  Цель анализа — оценить качество данных, описать структуру продаж,
  найти временные закономерности и аномалии, а также сформулировать
  гипотезы для дальнейшего исследования.
